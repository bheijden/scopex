Recipes

One runnable file per question, in examples/recipes/. Each was written while diagnosing a real pathology, names the case it came from, prints the numbers it was derived from, and says when its knob stops working.

20 recipes, all runnable: python examples/recipes/<name>.py · derived from the 28 arms in INVESTIGATIONS
recipes and investigations are two views of the same 28 cases Recipes are indexed by the QUESTION you arrived with — "which pass grew the module?" — and are runnable. Investigations are indexed by WHERE THE COST LIVED — upstream of XLA, inside one HLO pass, below HLO — and are the evidence: what each instrument showed, what it missed, and where the trail left scopex for XLA source. Start here if you have a slow compile. Go there if you want to know whether to believe a claim, or you want the reasoning rather than the command.
a recipe is a starting point, not a function These are meant to be copied and adapted. Most are below the bar for the package API — asked for by one or two investigations rather than used constantly — and a recipe shows the whole procedure where an API would hide it behind a name. If you find yourself reaching for the same one across three unrelated problems, that is the argument for promoting it.
